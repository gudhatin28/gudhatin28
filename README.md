### 03 · Mortgage Delinquency Risk Analytics
**Freddie Mac Loan-Level Data**

Analyzed approximately **22,500 mortgage loan records** and evaluated **4 machine-learning models**: Random Forest, Logistic Regression, Decision Tree, and SVM.

Compared **0.5%, 1.0%, and 1.5% risk-threshold scenarios**. The project estimated that excluding the highest-risk **1.5% of loans** could represent approximately **$2.06B in potential savings** while supporting a **98% loan-purchase objective**.

**Focus:** SQL · Python · Risk Analytics · Scenario Analysis · ML
